# TriCloud Connect 製品仕様書 v4.2

## 概要
TriCloud Connect は、社内システムと外部SaaSの間でデータを同期する統合基盤である。
2026年4月にメジャーバージョン4系をリリースした。

## 動作要件

| 項目 | 要件 |
| --- | --- |
| CPU | 4コア以上（推奨8コア） |
| メモリ | 16GB以上（推奨32GB） |
| ストレージ | 200GB以上 |
| OS | Ubuntu 24.04 LTS / RHEL 9 |
| データベース | PostgreSQL 16 以降 |

## 性能

標準構成における同期スループットは毎秒1,200レコードである。
最大同時接続数は5,000セッション、1バッチあたりの最大レコード数は50万件。
同期ジョブのタイムアウト既定値は3,600秒である。

## 制限事項
- 1テナントあたりのコネクタ登録数は上限100件
- 添付ファイルの同期は1ファイル512MBまで
- 削除操作の同期は論理削除のみに対応し、物理削除は同期対象外

## サポート
標準サポートの受付時間は平日9時00分から18時00分まで。
重大障害（サービス全体停止）に限り、24時間365日の受付窓口を提供する。
